АВТОМАТИЧЕСКАЯ НАРЕЗКА ПОЛНОЙ СЕРИИ
====================================

Подготовка
----------
1. FFmpeg и faster-whisper уже должны быть установлены.
2. Файл gameplay.mp4 должен лежать рядом с RUN.bat.
3. Положите одну полную серию в папку input.
4. Папку output перед запуском можно оставить пустой.

Запуск
------
Дважды нажмите RUN.bat.

При первом запуске Whisper скачает модель small. Нужен интернет и свободное место.
Распознавание полной серии на процессоре может занять продолжительное время.

Результат
---------
Программа создаёт до 6 роликов длиной 28–42 секунды:
- геймплей на полном экране;
- сцена сериала поверх;
- оригинальный звук сцены;
- дословные русские субтитры;
- без музыки и рекламной плашки.

В output также создаётся clips_manifest.txt с таймкодами и распознанными репликами.

Настройки
---------
Откройте config.json обычным Блокнотом.
clip_count — количество роликов.
min_duration / max_duration — минимальная и максимальная длина.
model — модель Whisper: base быстрее, small точнее.
movie_height — высота крупного кадра сериала.
movie_top — отступ кадра сериала сверху.
game_top — высота, с которой начинается игровая зона.

Важно
-----
Автоматический выбор основан на плотности реплик, вопросах, эмоциональных словах и отсутствии длинных пауз. Перед публикацией просмотрите результат.
Используйте только видео, на публикацию которого у вас есть права или законное основание.
